# BuildSprint 2026: Code for Everyday India

A responsive landing page for a fictional 24-hour hackathon organised by a GDG on Campus community. It explains the event, shows tracks, schedule and prizes, and lets visitors register through a demo form.

All names, prizes, sponsors, seat counts and statistics are fictional sample data.

## Live demo
https://deepak1204yadavcse.github.io/Hackthone_LandPage/

## Features
- Sticky navbar with smooth scrolling and a mobile menu
- Hero with event details, a live countdown and a Register button
- Registration form with front-end validation (demo only, nothing is sent)
- Four tracks, a tabbed two-day schedule, prize cards and sponsor placeholders
- FAQ accordion
- Keyboard navigation, semantic HTML and meta tags (Open Graph, Twitter, theme-color)
- Responsive layout down to 360px width

## Page sections
Navbar, Hero, Registration, Community stats, About, Tracks, Schedule, Prizes, Sponsors, FAQ, Footer

## Tech stack
HTML, CSS and vanilla JavaScript. No frameworks or external images.

## Project structure
index.html    page structure and content
style.css     design system and layout
script.js     countdown, tabs, FAQ, menu and form validation

## Run locally
Open index.html in any modern browser. No installation needed.
